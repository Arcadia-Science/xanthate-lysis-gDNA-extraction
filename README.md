# xanthate-lysis-gDNA-extraction

Analysis accompanying the Arcadia Science pub “A high-throughput method for genomic DNA extraction from Chlamydomonas.”

## Contents

- [`gdna-qc-analysis/`](gdna-qc-analysis/) — TapeStation, NanoDrop, and Qubit quality control, summary statistics, and figure panels.
- [`amplicon-seq-analysis/`](amplicon-seq-analysis/) — CC-124 vs CC-1373 amplicon strain-typing design and analysis.

Raw QC data (TapeStation, NanoDrop, and Qubit) and the AI-8632 sequencing reads are on [Zenodo](https://doi.org/10.5281/zenodo.23051267) (DOI: 10.5281/zenodo.23051267). The reads are in `xanthate_gDNA_2_zenodo/strain_typing/amplicon_sequencing_AI-8632/`. Each directory has its own README with requirements and how to run the scripts.
